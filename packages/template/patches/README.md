# patches/

Every `*.patch` and `*.diff` file of this directory is applied to the sources before
`prebuild.sh`, with `patch -f -p1`, in the byte order of the file names: when the order matters
give the files a numeric prefix, `00-first.patch`, `10-second.patch`. Any other file is ignored.

A selected variant directory may carry its own `patches/`: its files join the list, a file with
the same name as one of the recipe replaces it, an empty file cancels it. For gcc, binutils, glibc
and gdb the release branch patches live in `variants/version/<ver>/patches/`, generated by
`utilities/update_patches`. `utilities/pkg_show <group>/<name>` prints the resolved list.
